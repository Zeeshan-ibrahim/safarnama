# Claude Code workspace

Start Claude Code from the repository root. `CLAUDE.md` is the global project contract. Skills are focused playbooks under `skills/`; agents are bounded specialists under `agents/`.

First session: use `docs/CLAUDE_BOOTSTRAP_PROMPT.md`. It is assessment-only and should not change code. Review the repository assessment before approving implementation.

Do not add broad auto-approval permissions. Review permission prompts. Human approval is required for destructive operations, production access, deployments, secrets, cloud changes, and paid APIs.\n
