# Pakistan Travel Platform — Claude Code starter kit

Contains root project instructions, specialist agents, reusable skills, and a safe first-session workflow.

Copy/merge `CLAUDE.md`, `.claude/`, and `docs/` into the repository root. Do not overwrite existing files without reviewing differences. The product documents are assumed to live in `docs/`; adjust references if your paths differ.

Start Claude Code from the repo root and paste `docs/CLAUDE_BOOTSTRAP_PROMPT.md`. The first session should assess the repo only. Review its findings, approve one vertical slice, then use `docs/FEATURE_TASK_TEMPLATE.md`.

No broad auto-approval permissions are included. Review permission prompts and keep destructive operations, production access, deployments, secrets, cloud changes, and paid APIs behind human approval.
