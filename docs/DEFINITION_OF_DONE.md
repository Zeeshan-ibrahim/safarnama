# Definition of Done

- Meets agreed user outcome and acceptance criteria; respects MVP scope.
- Unsupported destinations and incomplete data are handled honestly.
- Estimates, uncertainty, assumptions, and freshness are clear.
- Domain logic follows repository conventions; boundaries and validation are sound.
- No secrets or personal data exposed; migrations are safe.
- Travel facts have provenance; unknown/stale facts are not presented as verified.
- Budget arithmetic reconciles; AI output is grounded and schema-validated.
- Regression tests added; relevant tests/lint/format/type checks run or blockers documented.
- UI has applicable loading, empty, error, validation, responsive, and accessibility states.
- Diff reviewed for unrelated changes; docs updated; handoff reports checks, assumptions, and risks.
